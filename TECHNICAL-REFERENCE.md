### 1.4 Entry Point

`apps/offline/src/entry.ts` — sets the OT-only deployment policy, sets the `NullAdapter`, and calls `init()`:
```ts
import { NullAdapter } from '@adapter-null/index.js';
import { setAdapter } from '@core/db.js';
import { OT_ONLY_DEPLOYMENT_POLICY, setDeploymentPolicy } from '@core/deployment-policy.js';
import { init } from '@core/main.js';
setDeploymentPolicy({ ...OT_ONLY_DEPLOYMENT_POLICY, ai: { ...OT_ONLY_DEPLOYMENT_POLICY.ai, allowedConnectSrc: __OT_AI_CONNECT_SRC__.split(/\s+/).filter(Boolean) } });
setAdapter(new NullAdapter());
init();
```

Offline LAN AI endpoints are build-allowlisted with `OT_AI_CONNECT_SRC`.

## 2. Security Layer

### 2.1 CSP (in built `dist/offline/index.html`)

| Directive | Value | Purpose |
|-----------|-------|---------|
| `default-src` | `'none'` | Deny all by default |
| `script-src` | SHA-256 hash of the single inlined script block + `'wasm-unsafe-eval'` | Hash prevents XSS; `'wasm-unsafe-eval'` allows WebAssembly compilation for the ONNX runtime (transformers.js WebLLM). Regenerated by `generate-csp.mjs` after every build. |
| `style-src` | `'unsafe-inline'` | Required for 177+ inline `style=` attributes in render functions; style hashes not used (when style-src contains hashes, browsers ignore unsafe-inline per spec) |
| `img-src` | `'self' data: blob:` | Permits base64 data URIs (file attachments) and blob URLs |
| `connect-src` | Offline: `'self' http://localhost:11434 http://127.0.0.1:11434` by default | Offline OT AI endpoint allowlist. Add internal LAN origins with `OT_AI_CONNECT_SRC`. Sync/enterprise profiles may allow cloud and Hugging Face endpoints. |
| `worker-src` | `blob:` | transformers.js WebLLM Web Worker |
| `object-src` | `'none'` | Block all plugins |
| `base-uri` | `'none'` | Prevent base tag injection |
| `trusted-types` | `nexus-crm nexus-crm-raw` | Only these two policy names may be registered |
| `require-trusted-types-for` | `'script'` | Any raw string to a DOM sink throws |

`generate-csp.mjs` runs automatically after every build, recomputes the SHA-256 hash of the bundled script block, writes it into the CSP meta tag, and writes `dist/offline/index.sha256`.

### 2.2 Trusted Types (`packages/core/src/trusted-types.ts`)

| Symbol | Type | Purpose |
|--------|------|---------|
| `_ttPolicy` | `TrustedTypePolicy \| null` | `nexus-crm` — HTML-escapes user data for innerHTML |
| `_rawPolicy` | `TrustedTypePolicy \| null` | `nexus-crm-raw` — passes safe template HTML unchanged |
| `patchInnerHTML` IIFE | side effect | Overrides `Element.prototype.innerHTML` so all string assignments route through `_rawPolicy` |

**Rule:** This module must be the **first import** in `main.ts`. Never call `trustedTypes.createPolicy('nexus-crm-raw', ...)` again.

### 2.3 XSS Sanitisation

`escH(s)` in `utils.ts` — escapes `&`, `<`, `>`, `"`, `'` and newlines. Must be applied to all user-visible strings before innerHTML interpolation.

## 5. Crypto Module

**File:** `packages/core/src/crypto.ts`

Handles Base64 helpers, key derivation, and AES-GCM encrypt/decrypt. Higher-level operations that compose vault functions (`initCrypto`, `changePassword`, backups) live in `vault.ts` to avoid circular imports.

### 5.1 Base64 Helpers

| Function | Signature | Notes |
|----------|-----------|-------|
| `u8ToBase64(u8)` | `(Uint8Array) → string` | Uses `Uint8Array.toBase64()` (Sep 2025) with 64KB-chunked `btoa` fallback. Replaces `btoa(String.fromCharCode(...))`. |
| `base64ToU8(b64)` | `(string) → Uint8Array` | Uses `Uint8Array.fromBase64()` with `atob` fallback. |

### 5.2 Key Derivation

| Function | Signature | Notes |
|----------|-----------|-------|
| `deriveKey(password, salt, iterations?)` | `async (string, Uint8Array, number) → CryptoKey` | PBKDF2-HMAC-SHA-256, AES-GCM-256, `extractable: false` |

### 5.3 AES-GCM

| Function | Signature | Notes |
|----------|-----------|-------|
| `aesEncrypt(key, data)` | `async (CryptoKey, unknown) → string` | JSON-serialises → encrypts → prepends 12-byte IV → `u8ToBase64` |
| `aesDecrypt(key, b64)` | `async (CryptoKey, string) → unknown` | `base64ToU8` → splits IV → decrypts → JSON-parses |

## 9. Database Module

**File:** `packages/core/src/db.ts`

In-memory store backed by vault (CRM data) and IDB (documents/conversations). Exposes all UI-facing DB helpers. Wires adapter pull/push into init/flush.

### 9.1 Adapter Wiring

| Function | Purpose |
|----------|---------|
| `setAdapter(a)` | Injects the active sync adapter (called from entry.ts) |
| `getAdapter()` | Returns current adapter |

### 9.2 Initialization & Flush

| Function | Purpose |
|----------|---------|
| `dbInit(cryptoKey)` | Sets `_dbKey`, loads vault into `_dbData`, loads IDB stores, runs `adapter.pull()` |
| `dbFlush()` | Encrypts `_buildCrmPayload()` → writes to IDB vault → fires `adapter.push()` → triggers `fsWriteVault()` if FS ready |

## 19. App Bootstrap

**File:** `packages/core/src/main.ts`

### 19.1 Exported Functions

| Function | Purpose |
|----------|---------|
| `init()` | `async () → void` — full startup sequence |
| `fullRender(state)` | Full re-render: sets `appEl.innerHTML`, re-binds all listeners |
| `appRenderWorkspace(view)` | Partial re-render: replaces only `#workspace-container` |

### 19.2 `init()` Startup Sequence

1. `initTheme()` — apply theme immediately
2. `checkFileIntegrity()` (non-blocking) — compares against `.sha256`; shows red banner on mismatch; skipped on `file://`
3. `navigator.storage.persist()` — requests persistent IDB storage
4. `_migrateLocalStorageToIDB()` — one-time localStorage → IDB migration
5. `fsInit()` — restore FS Access handle; recover vault from disk if IDB empty
6. `_wireHooks()` — inject all cross-module function references before first render
7. `loadSessionKey()` — if cached key valid → `afterUnlock(key)` → done
8. Otherwise → `renderAuth()` / `bindAuth()` → on success → `cacheSessionKey(key)` → `afterUnlock(key)`

### 19.3 `afterUnlock(key)` Sequence

1. `dbInit(key)` — load all CRM data; adapter pull
2. `setState({ authed: true, cryptoKey: key })`
3. `reloadData()` — push data into state
4. `checkDueDates()` — initial notifications
5. `aiSecretsRefresh()` — prime secrets cache
6. `fullRender(getState())` — render full UI
7. `getAdapter().stream(...)` — wire adapter remote-change stream
8. `subscribe(...)` — register state listener; optimises ephemeral updates (toast, timerElapsed) without full re-render
9. Keyboard handlers — `Ctrl+K` opens command palette; `Escape` closes overlays
10. `setInterval(checkDueDates, 60000)` — due-date polling
11. AI auto-reconnect if prior tier configured

### 19.4 `_wireHooks()`

Called once in `init()` before first render. Injects all cross-module function references:
- `setAIHooks(aiNeedsOnboarding, openAIWizard)` → state.ts
- `setRuntimeHooks(...)` → ai-runtime.ts
- `setAIUIHooks(...)`, `setAIUISchemas(...)` → ai-ui.ts
- `setAISettingsHooks(...)`, `setAIV2IDBHooks(...)` → ai-settings.ts
- `setTopbarHooks(...)`, `setSidebarFsHooks(...)`, `setDashHooks(...)`, `setWorkspaceHooks(...)`, `setCalendarHooks(...)`, `setPCHooks(...)`, `setRecordModalHooks(...)`, `setFilesHooks(...)`, `setDocsHooks(...)`, `setDocsAIHooks(...)`, `setDocsStreamHook(...)`, `setLibraryHooks(...)`, `setLibraryDocHooks(...)`, `setComponentsAIHooks(...)`, `setSettingsAIHooks(...)`, `setSettingsFsHooks(...)` → view modules

## 23. Developer Workflows

### Building and testing

```bash
pnpm run build:offline   # compile + CSP hash
# then open: dist/offline/index.html in Chrome or Edge
```

For an offline OT build that can reach an internal LAN AI server:

```bash
OT_AI_CONNECT_SRC="http://localhost:11434 http://127.0.0.1:11434 https://ai-server.internal" pnpm run build:offline
```

### Adding a new CRM store

1. Add store name to `STORES` in `constants.ts`
2. Add field schema to `getSCHEMAS()` in `views/record-modal.ts`
3. Add column definition in `renderListView` in `views/list-grid-kanban-spatial.ts`
4. Add an entry to `NAV_ENTRIES` in `views/sidebar.ts`; mirror it in the `sheetEntries` array inside `renderBottomTabs`
5. Add switch cases in `fullRender` and `appRenderWorkspace` in `main.ts`
6. Add to `globalSearch` `SEARCH_FIELDS` in `db.ts`
7. Rebuild: `pnpm run build:offline`

### Adding a new large-content store

Do **not** add to `STORES`. Instead:
1. Add to `IDB_STORES` in `constants.ts`
2. Create its object store in `_dataDbOpen()` in `idb-data.ts`
3. Route all reads through `_idbLoadStore`, writes through `_idbPutRecord`
4. Load it in `dbInit()` in `db.ts`

### Security rules summary

- `escH()` on every user string before `innerHTML`
- Never use `btoa(String.fromCharCode(...array))` — use `u8ToBase64()`
- Never create policy `nexus-crm-raw` a second time
- Never make `_dbKey` extractable
- Keep the four IDB databases separate
- `trusted-types.ts` must be first import in `main.ts`
- Rebuild after every source edit to keep CSP hashes current
